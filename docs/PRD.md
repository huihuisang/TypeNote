# MusicKeyBoard - 产品需求文档 (PRD)

## 1. 产品概述

**MusicKeyBoard** 是一款 macOS 原生键盘音乐应用，用户可以通过电脑键盘演奏各种乐器。应用支持加载乐谱（简谱、MusicXML、MIDI），并将键盘按键映射为音符，实现"按键即演奏"的体验。

## 2. 目标用户

- 音乐爱好者：想用键盘快速体验演奏乐趣
- 音乐教育场景：教师/学生用于简谱练习和教学
- 创意工作者：需要快速试听旋律和音色

## 3. 核心功能

### 3.1 键盘演奏

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 本地键盘监听 | App 前台时捕获键盘事件，零权限要求 | P0 |
| 全局键盘监听 | 后台也可触发演奏（需输入监控权限） | P1 |
| 顺序演奏模式 | 每按一键播放乐谱中的下一个音符 | P0 |
| 自定义映射模式 | 用户自定义键位到音符的映射 | P0 |
| 钢琴键位布局 | 默认 ASDFGHJK = 白键，WETYU = 黑键（DAW 标准） | P0 |
| 按键防重复 | 忽略系统按键重复事件 | P0 |

### 3.2 音频引擎

| 功能 | 描述 | 优先级 |
|------|------|--------|
| SoundFont 音色播放 | 基于 AVAudioUnitSampler 加载 SF2 音色库 | P0 |
| 多音色预加载 | 多个采样器实例并行挂载，切换零延迟 | P0 |
| 低延迟缓冲 | 256 帧缓冲区（~5.8ms @ 44.1kHz） | P1 |
| 音色选择 | 支持 General MIDI 标准乐器切换 | P0 |
| 力度控制 | 支持设置音符力度（velocity） | P1 |

### 3.3 乐谱解析

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 简谱解析 | 支持数字简谱格式（1-7, 升降, 八度, 时值） | P0 |
| MusicXML 解析 | 导入 MuseScore/Sibelius/Finale 导出的五线谱 | P0 |
| MIDI 文件解析 | 导入标准 MIDI 文件 | P1 |
| 统一音符模型 | 三种格式统一输出为 MusicNote 数组 | P0 |

### 3.4 用户界面

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 虚拟键盘显示 | 可视化显示键盘布局和当前按键状态 | P0 |
| 乐谱导入 | 文件选择器导入乐谱文件 | P0 |
| 简谱文本输入 | 直接在文本框输入简谱 | P0 |
| 乐器选择器 | 下拉选择当前乐器音色 | P0 |
| 演奏进度显示 | 顺序模式下显示当前/总音符数 | P0 |
| 设置面板 | 配置键位映射、音色、权限等 | P1 |

## 4. 技术约束

- **最低系统版本**: macOS 14.0 (Sonoma)
- **开发语言**: Swift 5.9+
- **UI 框架**: SwiftUI
- **音频框架**: AVFoundation (AVAudioEngine + AVAudioUnitSampler)
- **键盘监听**: NSEvent (本地) / CGEventTap (全局)
- **状态管理**: @Observable (Observation 框架)
- **音色库**: GeneralUser GS v1.471 (SF2, ~30MB, 免费商用)
- **MIDI 解析**: MidiParser (SPM, MIT)
- **无第三方音频库依赖**: 不使用 AudioKit

## 5. 非功能需求

- **延迟**: 按键到出声 < 15ms
- **内存**: 空闲状态 < 100MB（含音色库）
- **启动时间**: < 2s
- **权限**: 本地模式零权限；全局模式仅需"输入监控"

## 6. 不在范围内 (Out of Scope)

- MIDI 外部设备输入/输出
- 录音和回放功能
- 音效处理（混响、延迟等）
- 乐谱编辑器
- iOS/iPadOS 版本
